# 🏥 Healthcare Analytics Dashboard

This project presents a **Healthcare Analytics Dashboard** built using **Power BI Desktop**, aimed at providing valuable insights into hospital operations and patient metrics. It is designed to help hospital administrators and healthcare providers make informed decisions using real-time data visualization.

## 📊 Dashboard Features

The dashboard visualizes key performance indicators from hospital data including patient admissions, billing, diagnosis types, doctor feedback, and insurance claims.

### Key Metrics Visualized

- **Admit, Discharge, and Follow-up Dates**
